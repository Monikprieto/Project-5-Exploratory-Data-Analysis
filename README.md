# Project-5-Exploratory-Data-Analysis
Investigate data and gain insights.
Global Cybersecurity Threats (2015–2024)

This project performs an in-depth Exploratory Data Analysis (EDA) on a dataset of global cybersecurity threats reported between 2015 and 2024. The goal is to uncover insights, trends, and potential areas of concern across attack types, affected industries, regions, and responses.

Dataset

- **Name:** `Global_Cybersecurity_Threats_2015-2024.csv`
- **Source:** Aggregated from public cybersecurity reports and incident databases
- **Main Features:**
  - `Attack Type`
  - `Year`
  - `Country or Region`
  - `Security Vulnerability Type`
  - `Defense Mechanism Used`
  - `Industry`
  - `Resolution Time`
  - `Users Affected`

Tools & Libraries

- Python 3.12
- Jupyter Notebook
- Pandas
- Seaborn
- Matplotlib
